# สถานีพิมพ์ผลตรวจ — KMITL Expo

สแกน QR ด้วยมือถือ staff → โน้ตบุ๊กถอดรหัส จัดหน้า A4 แล้วสั่งพิมพ์ให้อัตโนมัติ
**ไม่ต้องกดอะไรเลย** และ **วันงานไม่ต้องใช้อินเทอร์เน็ต**

> แต่ต้อง**ติดตั้งที่บ้านที่มีเน็ตก่อน 1 รอบ** — เปิด `start.bat` ทิ้งไว้จนขึ้นเขียว
> โค้ดที่ clone มาเฉย ๆ ยังรันไม่ได้ ของที่ต้องโหลด (~490MB) ไม่ได้อยู่ใน repo
> **setup หน้างานสด ๆ โดยไม่มีเน็ตไม่ได้**

```
[มือถือ staff] --WiFi--> [โน้ตบุ๊ก Windows] --USB/WiFi--> [เครื่องพิมพ์ A4]
 เปิดกล้องค้าง            decode -> กันซ้ำ -> คิว -> render -> พิมพ์
```

QR ของ Pipek/Anura บรรจุ**ผลตรวจทั้งชุดไว้ในตัวมันเอง** (รูปแบบ `NQ1` + timestamp +
คู่ค่า float16) ไม่ใช่ ID ที่ต้องไปถามเซิร์ฟเวอร์ ระบบนี้จึงถอดรหัสเองในเครื่องได้
ทั้งบูธตัดเน็ตทิ้งได้เลย

## ติดตั้ง (ทำที่บ้าน ต้องมีเน็ต)

**ดับเบิลคลิก `start.bat`** ครั้งเดียวจบ — ไฟล์นี้เช็คให้เองว่าของครบหรือยัง
ถ้ายังก็โหลดให้ก่อนแล้วเปิด server กับหน้าควบคุมต่อเลย ครั้งต่อ ๆ ไปก็ดับเบิลคลิก
ไฟล์เดิม มันข้ามขั้นติดตั้งเอง ไม่ต้องพิมพ์คำสั่งอะไรเลย

ครั้งแรกจะโหลด 2 ก้อน ทั้งคู่**ไม่ได้อยู่ใน git** และอยู่คนละที่กัน:

| ก้อน | ขนาด | ไปอยู่ที่ |
|---|---|---|
| `node_modules` | ~140MB | ในโฟลเดอร์โปรเจกต์ |
| Chromium สำหรับจัดหน้า PDF | ~350MB | `%USERPROFILE%\.cache\puppeteer` |

ที่ต้องรู้คือ **ก้อนที่ 2 ไม่ได้ไปกับโฟลเดอร์โปรเจกต์** ก๊อปโฟลเดอร์ไปลงโน้ตบุ๊กอีกเครื่อง
แล้วไม่มีเน็ต จะยังพิมพ์ไม่ได้ ต้องเปิด `start.bat` ให้มันโหลดจบบนเครื่องนั้นก่อน

> ถ้าขึ้นว่ายังไม่มี **Node.js** ให้โหลดตัว LTS จาก <https://nodejs.org> ติดตั้งแล้ว
> เปิด `start.bat` ใหม่ นอกจากนี้ไม่ต้องลงอะไรเองอีก

**เลือกเครื่องพิมพ์จาก dropdown ในหน้าควบคุมที่เด้งขึ้นมา** — มันบันทึกลง `config.json`
ให้เอง ไม่ต้องแก้ไฟล์ด้วยมือ (อยากดูรายชื่อจาก command line ก็ `npm run printers`)

`config.json` เปิดแก้เองได้ถ้าอยากตั้งค่าอื่น:

```json
{
  "eventName": "KMITL EXPO 2026",
  "printer": "ชื่อเครื่องพิมพ์ - เลือกจากหน้าควบคุมได้เลย ไม่ต้องพิมพ์เอง",
  "port": 8443,
  "inkSaver": false,
  "mono": false
}
```

| ตัวเลือก | ความหมาย |
|---|---|
| `inkSaver` | `true` = ตัดพื้นสีของ chip/แถบคะแนน/กล่องข้อจำกัด **ถ้าใช้อิงค์เจ็ทควรเปิด** (แถบหัวข้อ สีคำตัดสิน และแถบระดับความเสี่ยงยังอยู่ครบ เพราะเป็นสีที่มีความหมาย) |
| `mono` | `true` = พิมพ์ขาวดำล้วน ใช้ตอนหมึกสีใกล้หมด — ทั้งใบถูกวาดเป็นโทนเทาตั้งแต่ต้น (โลโก้ ไอคอน หัวข้อ แถบระดับความเสี่ยง) แล้วสั่ง `monochrome` ไปที่ไดรเวอร์อีกชั้น ระดับความเสี่ยงยังแยกออกจากกันได้เพราะไล่เทาอ่อน→เข้มตามความเสี่ยง และมีคำกำกับอยู่แล้ว ติ๊กเปิด/ปิดได้จากหน้าควบคุม |
| `keepPDFs` | `true` = เก็บ PDF ที่พิมพ์แล้วไว้ใน `logs/history/` (`false` = ลบทิ้งหลังพิมพ์) — ในนั้นคือผลตรวจของผู้เข้าชม **ห้ามอัปโหลดขึ้นคลาวด์ และลบทิ้งหลังจบงาน** |
| `keepHTML` | `true` = เก็บ HTML ต้นทางไว้ด้วย ใช้ตอนไล่ปัญหาหน้าตารายงาน (ไฟล์ละ ~330KB เพราะฝังฟอนต์กับโลโก้ไว้ในตัว ปกติปิดไว้) |
| `port` | ถ้าโดนโปรแกรมอื่นชนให้เปลี่ยน |
| `dryRun` | `true` = ทำงานทุกอย่างยกเว้นสั่งพิมพ์จริง ใช้ซ้อมทั้งระบบโดยไม่เปลืองกระดาษ |
| `showTicket` | `false` = ซ่อน chip "คิว" ได้หน้าตาเท่าต้นฉบับเป๊ะ (แต่จับคู่กระดาษกับคนยากขึ้น) |

### ทดสอบทั้งระบบโดยไม่เปลืองกระดาษ

ตั้ง `"dryRun": true` ใน `config.json` แล้วเปิด `start.bat` จากนั้นอีกหน้าต่างหนึ่ง:

```powershell
node test-load.mjs 20      # จำลอง 20 คนยิงพร้อมกัน
```

จะเช็คให้ครบว่า: ปฏิเสธ QR ที่ไม่ใช่ผลตรวจ, กันสแกนซ้ำ, สั่งพิมพ์ซ้ำ,
เลขคิวไม่ชนกัน, คิวระบายหมดไม่ค้าง, และตัวนับคิวตรงกับจำนวนจริง
**เสร็จแล้วอย่าลืมตั้ง `dryRun` กลับเป็น `false`**

### ลองดูหน้าตารายงานก่อน

```powershell
node preview.mjs "https://aqn.iamhtlife.com:8382/?r=TlEx8B5om..."
```

ได้ `preview.pdf` ออกมา เปิดดู ปรับ `lib/report.mjs` ได้ตามใจ

```powershell
node check-fit.mjs         # ทดสอบกรณีข้อมูลครบทุกตัว 26 แถว
```

`check-fit.mjs` ตรวจ 2 อย่าง: **อยู่ใน 1 หน้าไหม** และ **มีข้อความล้นกรอบไหม**

ข้อหลังสำคัญมากกับภาษาไทย เพราะสระบนกับวรรณยุกต์ลอยสูงกว่าตัวอักษรละติน
ถ้าไปล็อกความสูงกล่องไว้ตายตัว ตัวหนังสือจะปีนไปทับบรรทัดบนโดยที่ดูจาก
หน้าเว็บไม่เห็น เห็นตอนออกเป็น PDF แล้วเท่านั้น **ใน `lib/report.mjs` จึงใช้
`min-height` เสมอ ห้ามใช้ `height` กับกล่องที่มีข้อความไทย**

**แก้ `lib/report.mjs` ทีไรให้รัน `check-fit.mjs` ทุกครั้ง** — QR บางใบมีค่าครบกว่าใบอื่น
(เช่นมีอุณหภูมิร่างกายด้วย) ถ้าไม่เช็คจะไปเจอตอนกระดาษออกมา 2 แผ่นหน้างาน

## รันวันงาน

**ดับเบิลคลิก `start.bat`** — หน้าควบคุมจะเปิดขึ้นมาเองเมื่อ server พร้อม
ส่วนในหน้าต่างดำจะขึ้นลิงก์แบบ `https://192.168.x.x:8443` เอาไปเปิดบนมือถือ staff
หรือให้มือถือสแกน QR ที่อยู่บนหน้าควบคุมเลยก็ได้ ง่ายกว่าพิมพ์ IP เอง

> **สำคัญ:** ครั้งแรกมือถือจะขึ้นหน้าเตือนสีแดงว่า "การเชื่อมต่อไม่เป็นส่วนตัว"
> ให้กด **ขั้นสูง → ดำเนินการต่อ** นี่เป็นเรื่องปกติเพราะเราใช้ certificate ที่สร้างเอง
> **ต้องซ้อมข้อนี้ที่บ้านก่อน** ถ้าไม่ผ่านหน้านี้ กล้องจะไม่ทำงานเลย

หน้าควบคุมบนโน้ตบุ๊ก: `https://localhost:8443/control.html` — ในนั้นมี QR สำหรับให้มือถือ
staff สแกนเข้าเว็บ, เลือก/ดูสถานะเครื่องพิมพ์, หยุด-ล้างคิว, รีสตาร์ทตัวจัดคิวของ Windows,
ตัวนับงาน, รายการคิวล่าสุด (สั่งพิมพ์ซ้ำเป็น TH / EN / Both ได้ทีละใบ) และช่องติ๊กตั้งค่า

### วิธีใช้ของ staff

- เล็ง QR ในกรอบ → เจอแล้วมันจะถามภาษาก่อน **TH / ENG / Both** มีเวลา 3 วินาที
  ไม่กดอะไรเลยจะเป็น TH ให้เอง (Both = พิมพ์ 2 แผ่น ไทยใบอังกฤษใบ)
- ส่งแล้ว → **เขียว + ติ๊ง = เข้าคิวแล้ว** ตัวเลขใหญ่คือหมายเลขคิว
- **เหลือง** = สแกนซ้ำ ไม่พิมพ์ให้ (คนนี้พิมพ์ไปแล้ว)
- **แดง** = มีปัญหา อ่านข้อความข้างล่าง
- ปุ่มไฟฉายอยู่มุมขวาบน (ถ้ามือถือรองรับ)
- ปุ่ม **พิมพ์คิว NNN อีกครั้ง** โผล่ใต้ปุ่มยกเลิก หลังส่งใบล่าสุดสำเร็จ กดแล้วยังไม่พิมพ์
  — จะขึ้นกล่องให้เลือก **TH / ENG / Both** อีกรอบ (หรือ **ไม่พิมพ์**) เลือกแล้วถึงสั่งจริง
  กันเผลอไปโดนแล้วได้ผลตรวจของคนอื่นออกมาเกิน
- ปุ่มนี้**ไม่หายตอนกดยกเลิกคิว** เพราะยกเลิกแล้วสั่งใหม่คือทางแก้ตอนเลือกภาษาผิด:
  ยกเลิก → กดปุ่มนี้ → เลือกภาษาที่ถูก
- ถ้าใบนั้นยังรอพิมพ์อยู่จะขึ้นว่า "คิวนี้ยังรอพิมพ์อยู่" ให้รอให้ออกก่อนค่อยกด
- ย้อนไปพิมพ์ซ้ำ**ใบเก่ากว่านั้น** ทำที่หน้าควบคุมบนโน้ตบุ๊ก เลือก TH / EN / Both ได้ทีละใบ

- [ ] ลองสแกน 1 ใบแล้วกด **Both** ดูว่าออกครบ 2 แผ่น

      "Microsoft Print to PDF" หรือ "OneNote" — พวกนี้รับงานแล้วไม่ออกกระดาษ
      (ถ้าเลือกผิดไว้ มือถือจะขึ้นเตือนแถบแดงให้เอง)
- [ ] เปิดหน้าเว็บบนมือถือ staff **ทุกเครื่อง** ผ่านหน้าเตือน https แล้ว bookmark ไว้
- [ ] **ปิดโหมด Sleep ของเครื่องพิมพ์** (ตั้งเป็นค่าสูงสุด/ปิด) ← ข้อนี้สำคัญที่สุด
      เครื่องเลเซอร์ที่หลับไปจะใช้เวลา warm-up 15–20 วินาทีต่อคน
- [ ] ปิด Sleep ของ Windows ด้วย (Settings → Power → Screen and sleep → Never)
- [ ] ทดสอบยิงรัว 20 ใบติดกัน ดูว่าคิวไม่ค้าง
- [ ] จดชื่อ+รหัส WiFi ที่จะใช้ไว้ ถ้าใช้ hotspot ของ Windows ให้ลองล่วงหน้า
      (แนะนำ router พกพาตัวละ ~300 บาท เสถียรกว่า Mobile Hotspot ของ Windows มาก)

## เวลาเกิดปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| มือถือขึ้น "เปิดกล้องไม่ได้ ต้องเป็น https" | เข้าผ่าน `http://` ให้พิมพ์ `https://` นำหน้าเอง |
| กล้องขึ้นแต่สแกนไม่ติด | แสงน้อย → เปิดไฟฉาย / ถือห่าง 15–25 ซม. / เช็ดเลนส์ |
| ขึ้น "ต่อโน้ตบุ๊กไม่ได้" | มือถือหลุด WiFi หรือหน้าต่าง server ปิดไป |
| สแกนติดแต่ไม่ออกกระดาษ | ดู `control.html` → ถ้าค้างที่ "กำลังพิมพ์" ให้เช็คคิวใน Windows |
| ขึ้น "เลือกเครื่องพิมพ์ที่พิมพ์ลงไฟล์อยู่" | หน้าควบคุมเลือก Microsoft Print to PDF / OneNote ไว้ เปลี่ยนเป็นเครื่องจริงในดรอปดาวน์ |
| เลือกภาษาผิด / กด Both ทั้งที่ไม่ต้องการ | กด **ยกเลิกคิวนี้** ทัน (มีเวลา 9 วิ) แล้วกด **พิมพ์คิว NNN อีกครั้ง** เลือกภาษาใหม่ — ถ้ากระดาษออกไปแล้วก็กดปุ่มเดิมได้ ใบเก่าทิ้ง |
| ขึ้น "ไม่ใช่ QR ผลตรวจ" | สแกนโดน QR อื่น (โปสเตอร์/ป้าย) — เล็งใหม่ |
| เครื่องพิมพ์ตายกลางงาน | ข้อมูลไม่หาย ทุกการสแกนอยู่ใน `logs\scans.csv` ครบ พิมพ์ย้อนหลังได้ |
| กดลบงานในคิวแล้วไม่หาย | Windows รับคำสั่งแล้วค้างที่สถานะ Deleting — เกิดตอนเครื่องพิมพ์หลับ/หลุด Wi-Fi ปลุกเครื่องพิมพ์ก่อน ถ้ายังค้างกด **รีสตาร์ทตัวจัดคิว** (ล้างคิวทั้งเครื่อง ต้องกดยืนยันหน้าต่าง Windows) |
| ระบบล่มหมด | fallback: ให้ผู้เข้าชมสแกน QR ด้วยมือถือตัวเอง หน้าเว็บเดิมมีปุ่ม Export PDF อยู่แล้ว |

## ข้อมูลส่วนบุคคล

`logs\scans.csv` เก็บ URL ที่สแกน ซึ่ง**มีผลตรวจสุขภาพของผู้เข้าชมอยู่ในนั้น**
และ `logs\history\` เก็บใบที่พิมพ์ไปแล้วทั้งหมด (ตราบใดที่ `keepPDFs` ยังเป็น `true`)
ทั้งสองอย่างเก็บไว้ในเครื่องอย่างเดียว อย่าอัปขึ้น cloud/ไลน์กลุ่ม และ**ลบทิ้งหลังจบงาน**
— ทั้งโฟลเดอร์ `logs/` อยู่ใน `.gitignore` แล้ว จะได้ไม่หลุดขึ้น repo โดยไม่ตั้งใจ

## รูปแบบรายงาน

ลอกจาก `รายงานผลคัดกรองสุขภาพ_PIPEK_A4.pdf` โดย**วัดจากไฟล์จริง** ไม่ได้กะเอา:

- โลโก้ SMC กับ PIPEK ดึงเป็นบิตแมปออกมาจากตัว PDF ต้นฉบับ (อยู่ใน `assets/` คู่กับ
  ตราสถาบัน) ย่อเหลือสูง 200px และลดสีเหลือ 5 บิตต่อช่องแล้ว — บนกระดาษไม่ต่าง
  แต่ทั้งสามไฟล์รวมกันเหลือ 98KB จาก 252KB และแต่ละใบเบาลงตามไปด้วย
- สีทั้ง 5 ระดับใช้แถบ "ระดับความเสี่ยงและความหมาย" ของหน้าผลตรวจ PIPEK
  (`#008609` `#90bd17` `#cfb000` `#ed7e2f` `#d71014`) กระดาษกับจอจะได้พูดตรงกัน
  — เฉพาะสีที่ 2 ตอนเป็นตัวเลขหนาบนกระดาษขาวใช้เขียวเข้มขึ้น (`#7ba30f`) เพราะ
  `#90bd17` จางเกินไป
- โหมด `mono` มีชุดเทาของตัวเองไล่อ่อน→เข้มตามความเสี่ยง ไม่ได้แปลงจากสีตรง ๆ
  เพราะถ้าคิดตามความสว่าง `#008609` (ดี) กับ `#d71014` (ไม่ดี) ออกมาเทาเกือบเท่ากัน
  — แถบซ้ายของแต่ละแถวใช้เทาเข้มพอจะไล่ลำดับ ส่วนตัวเลขกับคำตัดสินใช้เทาที่อ่านออก
  ที่ 13px คนละค่ากัน
- ระยะทั้งหมดวางเป็นพิกเซล A4 ที่ 96dpi (794x1123) ตรงกับที่วัดได้จากต้นฉบับ:
  ขอบ 38px, คอลัมน์ 354px เว้น 10px, หัวหมวดสูง 31px, แถวสูง ~42.8px
- `@page` margin เป็น 0 แล้วใส่ขอบที่ `body` แทน เพื่อไม่ให้ pipeline การพิมพ์ขยับเลย์เอาต์

**เพิ่มจากต้นฉบับอย่างเดียวคือ chip "คิว"** ปิดได้ด้วย `"showTicket": false`

ใบเดียวกันออกได้ 3 แบบ: `TH` `ENG` และ `BOTH` (ไทย 1 แผ่น อังกฤษ 1 แผ่น ในไฟล์เดียว)
staff เลือกตอนสแกน หรือกดสั่งพิมพ์ซ้ำเป็นภาษาไหนก็ได้จากหน้าควบคุม — โหมด `BOTH`
ฝังฟอนต์ โลโก้ และไอคอนไว้ชุดเดียวใช้ร่วมกันทั้งสองแผ่น ไม่ได้ฝังซ้ำหน้าละชุด

หัวกระดาษวางตราสถาบัน สจล. → PIPEK → SMC ไว้กึ่งกลาง และ**ไม่มี QR บนใบแล้ว**
(ของเดิมเป็น QR ชี้กลับไปหน้าผลตรวจ) ส่วน QR ที่ยังใช้อยู่คือ QR บนหน้าควบคุม
สำหรับให้มือถือ staff สแกนเข้าเว็บเท่านั้น

ทั้ง 6 หมวดมีสีประจำหมวด + เลขกำกับในวงกลม (แบบเดียวกับหน้าผลตรวจ) และเว้นช่องว่าง
ระหว่างกล่อง 8px เพราะตอนที่ทุกหมวดใช้ฟ้าสีเดียวกันและวางชิดกัน มันอ่านรวมเป็นก้อนเดียว

ไอคอนหน้าแต่ละรายการคือไฟล์เดียวกับที่หน้าผลตรวจใช้ (`assets/svg/<POINT_ID>.svg`)
ฝังลงใน HTML ตอน render จึงไม่ต้องต่อเน็ต — ตอนโหลดต้องแก้ 2 อย่าง:
เติม prefix ให้ทุก `id` ในไฟล์ (ไม่งั้น clip-path ของไอคอนแรกจะทับของตัวถัดไป
เพราะ 26 ไอคอนอยู่ในเอกสารเดียวกัน) และเปลี่ยน `fill="black"` เป็น `currentColor`
เพื่อให้ไอคอนรับสีหัวข้อได้ อีก 3 ไอคอน (SLEEP_QUALITY, ANXIETY_INDEX, VITALITY)
เป็น PNG โปร่งใสห่อใน SVG `currentColor` ไม่มีผลกับบิตแมป — **เคยลองใช้ CSS mask
แล้วบนจอถูกต้องแต่พิมพ์ออกมาเป็นสี่เหลี่ยมทึบ 3 อัน** เพราะ pipeline การพิมพ์ทิ้ง mask
เหลือแต่พื้นหลัง ตอนนี้เลยย้อมสีที่ระดับพิกเซลตอนโหลด (คง alpha เดิม เปลี่ยนแค่สีดำ)
แล้วฝังเป็น `<img>` — ห้ามกลับไปใช้ mask อีก

คำตัดสิน 5 ขั้นคำนวณจาก scale segments ใน `data.js` ของเว็บต้นทางโดยตรง ใช้คำบอก
"ค่านี้ดีแค่ไหน" แทนคำของ PIPEK ที่บอกทิศทาง (ปกติ / ต่ำ / ปานกลาง / ค่อนข้างสูง / สูง)
เพราะในใบเดียวกันบางตัวสูงคือดี บางตัวต่ำคือดี "สูง" ข้างคะแนนการนอนคือข่าวดี

| ระดับ | ไทย | ในแถบสี (บรรทัดสอง) | อังกฤษ | บรรทัดสอง |
|---|---|---|---|---|
| 1 | ดี | — | Good | — |
| 2 | ปานกลาง | — | Fair | — |
| 3 | เฝ้าระวัง | — | Caution | — |
| 4 | ไม่ค่อยดี | ค่อนข้างเสี่ยง | Poor | At risk |
| 5 | ไม่ดี | เสี่ยง | Very poor | High risk |

บรรทัดสองขึ้นเฉพาะในแถบ "ระดับความเสี่ยงและความหมาย" และเฉพาะสองขั้นล่าง เพราะ
เป็นสองขั้นที่ต้องบอกให้ชัดว่าหมายถึงความเสี่ยง ส่วนคำตัดสินท้ายแถวเหลือคำเดียว —
ช่องละ 65px ที่ 12.8px ใส่ได้แค่คำตัดสิน ไม่ใช่ประโยค — ดูเหตุผลของวิธีแยก
ขั้นที่ 2 กับขั้นที่ 4 ได้ในคอมเมนต์ของ `levelOf()` ใน `lib/layout.mjs`

ชื่อรายการภาษาไทยและการจัดหมวด (หัวใจและสัญญาณชีพ / สรีระร่างกายและน้ำหนัก /
ความเครียดและการนอนหลับ / สมรรถนะของร่างกาย / ความเสี่ยงด้านสุขภาพ) ใช้คำเดียวกับ
หน้าผลตรวจบนมือถือ เพื่อให้ผู้เข้าชมเทียบใบกับจอได้ทันที ส่วนแถวความเสี่ยงตัดคำว่า
"ความเสี่ยง" ออก เพราะหัวหมวดบอกอยู่แล้ว

```
start.bat            ดับเบิลคลิกไฟล์เดียว: เช็คของ ติดตั้งถ้ายังไม่มี แล้วเปิด server

preview.mjs          render PDF ทดสอบจาก QR จริง โดยไม่พิมพ์
check-fit.mjs        ทดสอบว่ากรณีข้อมูลครบยังอยู่ใน 1 หน้า
assets/              ตราสถาบัน สจล. + โลโก้ SMC/PIPEK + assets/svg/ ไอคอน 26 ตัวจากหน้าผลตรวจ
config.json          ตั้งค่าทั้งหมด
lib/decode.mjs       ถอดรหัส QR (พอร์ตจาก results-app.js ของเว็บต้นทาง)
lib/points.mjs       ช่วงค่าปกติ/เกณฑ์สี 33 ตัว (สร้างจาก data.js ของเว็บต้นทาง)
lib/layout.mjs       ผังรายงาน PIPEK: ชื่อไทย/อังกฤษ, คอลัมน์, ลำดับ, การตัดสินระดับ 5 ขั้น
lib/report.mjs       เทมเพลตรายงาน A4 (ทั้งโหมดสีและขาวดำ)
lib/printer.mjs      อ่านสถานะ/คิวเครื่องพิมพ์ของ Windows และสั่งหยุด-ล้าง-ลบงาน
lib/fonts.mjs        ฝังฟอนต์ไทยลงในไฟล์ report
public/index.html    หน้าสแกนบนมือถือ
public/control.html  หน้าควบคุมบนโน้ตบุ๊ก
logs/scans.csv       บันทึกทุกการสแกน
logs/history/        ใบที่พิมพ์ไปแล้ว (ดู keepPDFs)
```
